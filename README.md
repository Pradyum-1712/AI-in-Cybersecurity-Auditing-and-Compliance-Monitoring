# AI in Cybersecurity Auditing and Compliance Monitoring - Systematic Literature Review

## Project Overview
This repository contains a comprehensive systematic literature review (SLR) on AI applications in cybersecurity auditing and compliance monitoring, covering 40 research papers published between 2022-2025.

## Getting Started
1. Install dependencies: `pip install -r requirements.txt`
2. Run the master pipeline: `jupyter notebook analysis/00_slr_pipeline.ipynb`
